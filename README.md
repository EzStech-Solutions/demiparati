# MiSitio - Base para sitio web

Este repositorio contiene una base simple para iniciar un sitio web estático.

## Estructura

- `/home/runner/work/demiparati/demiparati/index.html` - Página principal
- `/home/runner/work/demiparati/demiparati/style.css` - Estilos del sitio
- `/home/runner/work/demiparati/demiparati/script.js` - Comportamiento JavaScript
- `/home/runner/work/demiparati/demiparati/assets` - Recursos estáticos (imágenes, audio, etc.)

## Uso

1. Abre `/home/runner/work/demiparati/demiparati/index.html` en tu navegador.
2. Edita los contenidos y estilos según tu proyecto.
3. Publica en GitHub Pages, Netlify o Vercel.
